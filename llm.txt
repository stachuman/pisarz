# LLM Integration Implementation Plan - Pisarz

## Overview

**LLM Assistant** - AI-powered writing companion integrated into Pisarz application. Provides context-aware suggestions, text improvements, character development, and creative assistance through a hybrid UI approach (docked panel + optional detached window).

## Core Principles

| Principle | Description | Benefit |
|-----------|-------------|---------|
| **P1** **One feature at a time** – small, vertical slices. | Easier to reason about in LLM prompts. | Maintainable development |
| **P2** **Readable > perfect** – doc‑strings, type hints, no premature abstraction. | Future self will thank you. | Code quality |
| **P3** **SQLite first** – single `pisarz.db` in project folder. | Zero external deps; easy to inspect. | Simplicity |
| **P4** **i18n from day 1** – all user‑visible strings via `tr()` in QML and `gettext` in Python. | Later localisation costs drop. | Global readiness |
| **P5** **proper logging** – proper logging for each components as defined in logging_config.py. | Later logging fixing is costy. | Global readiness |


## Architecture Overview

```
UI Layer (QML)
├─ LLMAssistantPanel (docked) / LLMAssistantWindow (detached)
├─ TaskSelector (buttons with parameters)
├─ SmartContextPicker (auto-detection + manual selection)
└─ ChatInterface (streaming responses)

Control Layer (Python)
├─ AppLLMController (main coordinator)
├─ LLMWindowManager (docked vs detached mode)
└─ LLMUIController (UI state management)

Service Layer (Python)
├─ LLMService (async main service)
├─ LLMContextManager (context building + detection)
├─ LLMTaskRegistry (parametrized tasks)
├─ LLMTemplateEngine (Jinja2 templates)
├─ LLMProviders (OpenAI/Claude/Ollama)
└─ LLMCache (async SQLite cache)
```

## Database Schema Additions

```sql
-- LLM cache table
CREATE TABLE IF NOT EXISTS llm_cache (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    cache_key TEXT UNIQUE NOT NULL,
    task_id TEXT NOT NULL,
    response TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    expires_at DATETIME
);

-- LLM settings
CREATE TABLE IF NOT EXISTS llm_settings (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- LLM conversation history
CREATE TABLE IF NOT EXISTS llm_conversations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id INTEGER NOT NULL,
    scene_id INTEGER,
    task_id TEXT NOT NULL,
    prompt TEXT NOT NULL,
    response TEXT NOT NULL,
    context_data TEXT,  -- JSON
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects (id),
    FOREIGN KEY (scene_id) REFERENCES scenes (id)
);

-- Indexes for performance
CREATE INDEX IF NOT EXISTS idx_llm_cache_key ON llm_cache (cache_key);
CREATE INDEX IF NOT EXISTS idx_llm_cache_expires ON llm_cache (expires_at);
CREATE INDEX IF NOT EXISTS idx_llm_conversations_project ON llm_conversations (project_id);
CREATE INDEX IF NOT EXISTS idx_llm_conversations_scene ON llm_conversations (scene_id);
```
